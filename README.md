# Mateza Booking Dashboard

Our dashboard is the main admin portal for the restaurant.

## 1. Code Stack 🧑‍💻

This code is in React and Node.js.

## 2. International Collaboration ❤️

This project is between Belgium and Spain. We are working to create Mateza 4.0. The fourth generation of our restaurant reservation platform.

## 3. Running this Code 💫

npm install --legacy-peer-deps

npm start
